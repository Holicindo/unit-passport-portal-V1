## 🔗 Internal Linking Strategy

### Aturan Linking
1. **Cluster Linking:** Artikel dalam kelompok yang sama saling terhubung
2. **Cross-Cluster Linking:** Kelompok A & B menautkan ke minimal 1 artikel di Kelompok C
3. **Pillar Content (C5):** Artikel integrasi 3 tema menerima link dari minimal 2 artikel A dan 2 artikel B
4. **Anchor Text:** Berbasis kata kunci target (BUKAN "klik di sini")
5. **Circular Linking:** Maksimal 2 tingkat (A1 → C1 → C5 ✅ | A1 → C1 → C4 → C5 ❌)

### Peta Linking Utama
```
KELOMPOK A (Pencahayaan) ──→ KELOMPOK C (Pillar)
                            ↗
KELOMPOK B (Suhu Ruangan) ──→ KELOMPOK C (Pillar)

Artikel C5 (Integrasi) = HUB UTAMA
```
